Project Overview
Transform the existing single-page videography portfolio website into a multi-page platform called "Mik3verse" with a landing page that routes to three distinct portfolio sections, each maintaining design consistency while expressing unique niche-specific aesthetics.

Current State
✅ Fully functional single-page videography portfolio ("Mik3shotit")
✅ Cyberpunk/sci-fi aesthetic with terminal fonts and neon glows
✅ Sections: Hero, About, Services (with hover carousel), Pricing, Gallery, Contact
✅ Responsive design with mobile optimization
✅ Framer Motion animations throughout
✅ SEO optimized with meta tags and sitemap
Required Changes
1. Create Landing Page ("Mik3verse")
Purpose: Central hub that serves as the main entry point to three portfolio sub-sites

Components Needed:

Hero Section:

Large "MIK3VERSE" title with terminal/neon aesthetic
Tagline: "Creative • Technical • Physical" or similar
Background: Subtle animated grid or particle system
Three Navigation Buttons (Primary Feature):

Button 1: "MIK3SHOTIT" → Videography/Photography Portfolio (existing)
Button 2: "[PLACEHOLDER_TECH]" → Tech/IT Portfolio + CV Section
Button 3: "[PLACEHOLDER_FITNESS]" → Fitness/Lifestyle Portfolio
Button Design Requirements:

3D Parallax Effect: Buttons should have depth and respond to mouse/scroll position

Scroll-Reveal Animation: Buttons dramatically appear as user scrolls down

Modern 3D Design Elements:

Layered shadows for depth
Tilt effect on hover (using mouse position)
Perspective transforms (rotateX, rotateY)
Smooth spring physics animations
Gradient borders with animated glow
Inner shadows and highlights for 3D appearance
Interactive States:

Idle: Subtle floating/breathing animation
Hover: Lifts up (translateZ), tilts based on cursor position
Click: Smooth transition/morph animation before navigation
Recommended Technologies:

Framer Motion for animations
CSS 3D transforms (preserve-3d, perspective)
Mouse tracking for parallax tilt effect
Intersection Observer for scroll-reveal
Layout:

Full-screen landing page
Buttons arranged vertically or in a grid (designer's choice)
Each button should be substantial in size (200-300px height)
Adequate spacing between buttons (80-120px gap)

Use React Router (or similar) to create multi-page structure

Routes needed:

/ → Landing page (Mik3verse)
/videography or /mik3shotit → Current videography portfolio
/tech or /[placeholder-tech-name] → Tech/IT portfolio (to be developed)
/fitness or /[placeholder-fitness-name] → Fitness portfolio (to be developed)
Navigation Considerations:

Add "Back to Mik3verse" button in header of sub-sites
Maintain smooth page transitions
Preserve scroll position behavior
Update browser history correctly
