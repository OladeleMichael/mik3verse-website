# MIK3VERSE Portfolio (Vite + React)

This project is configured to run instantly with Vite.

## Scripts

- `npm run dev` – start dev server at http://localhost:5173
- `npm run build` – build for production (outputs to `dist/`)
- `npm run preview` – preview the production build locally

## Notes

- Entry HTML is `index.html` at the repo root (Vite default). It loads `/src/main.jsx` which mounts React into `#root`.
- Static assets live in `public/` and are served at the site root.

## Quick start

1. Install deps
   ```powershell
   npm i
   ```
2. Start dev server
   ```powershell
   npm run dev
   ```
3. Open http://localhost:5173
